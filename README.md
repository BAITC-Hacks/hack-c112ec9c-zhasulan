# FAQ-бот на 5 вопросов

Небольшой терминальный бот для репетиции трека «LLM-приложения». Он читает пять пар вопрос–ответ из `faq.txt`, ищет ближайшую тему по ключевым словам и отвечает `не знаю`, если совпадение слишком слабое. LLM и сторонние пакеты не используются.

## Требования

- Python 3.10 или новее

## Запуск

```bash
python bot.py
```

В Windows также можно запустить так:

```powershell
py bot.py
```

Введите вопрос в свободной форме. Для завершения введите `выход` или нажмите `Ctrl+C`.

Пример:

```text
FAQ-бот репетиции. Задайте вопрос (для выхода: выход).
Вы: Как отправить работу?
Бот: Сдайте репозиторий с командами запуска и README, в котором кратко описано, что получилось.
Вы: Какая сегодня погода?
Бот: не знаю
```

## Как это работает

1. `faq.txt` содержит пять блоков с полями `Вопрос`, `Ключевые слова` и `Ответ`.
2. Бот приводит текст к нижнему регистру, убирает служебные слова и учитывает разговорные синонимы.
3. Для каждого блока считается совпадение ключевых слов; небольшие опечатки допускаются.
4. Если лучший результат ниже порога, бот печатает `не знаю`.

Ответы и ключевые слова можно менять прямо в `faq.txt`, не редактируя код.
